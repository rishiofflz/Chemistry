## GitHub / Streamlit deployment

1. Upload `streamlit_app.py` and `requirements.txt` to the root of your existing chemistry repository\.
2. In Streamlit Community Cloud, set **Main file path** to `streamlit_app.py`\.
3. Deploy or reboot the app\.

The 3D viewer requires RDKit and py3Dmol\. If deployment reports a dependency error, inspect the Streamlit build logs\.
